A1 · 语言发展史：谁在什么年代造了哪门语言 AIE Week1

语言作者年代一句话特征
CDennis Ritchie1969–1973贝尔实验室；介于汇编与高级语言之间，能直接操作内存，高级语言里执行效率最高
C++Bjarne Stroustrup1979 起继承 C 的主要特性，加入面向对象、支持代码复用，仍平台相关
JavaJames Gosling1995Sun 公司；平台无关，"write once, run anywhere"
PythonGuido van Rossum1989 开发 / 1991 发布开源、面向对象、库丰富、能接 C/C++/Java；2010 年年度语言

怎么考：选择题直接问「Python 是谁在哪一年发布的」「哪门语言平台无关」。记两张卡片就够： Python = Guido van Rossum = 1991；Java = Gosling = 1995 = WORA。

A2 · 抽象层次：从机器语言一路到 Python AIE Week1

课件给了两条抽象链，选择题爱考「越往上越怎样」：

机器语言 → 汇编语言 → C → Python        （越低执行越快，越高写起来越快）
硬件 → 操作系统 → 应用软件                 （OS 是最底层的程序，提供基本服务）
二进制位 → 基本数据类型 → 数据结构

结论：越高级的语言 开发效率越高、执行效率越低，且不能直接执行，必须先翻译成低级语言。 这条和本站 T1 的「开发效率 vs 执行效率反向」是同一件事，只是 AIE 多给了这条链。

A3 · 常量：Python 里没有真常量，全大写只是约定 AIE Week2

PI = 3.14159        # 约定：全大写 = 提醒自己和别人别改
PI = 3              # 语法上完全合法，运行时不会报错

怎么考：判断题「Python 可以用 const 声明常量」→ 错。 Python 没有 const / final 关键字，靠命名约定（全大写）表达「这个值不该改」。

A4 · divmod()：一次拿到商和余数 AIE Week2

divmod(7, 3)      # (2, 1)     等价于 (7 // 3, 7 % 3)
divmod(-7, 3)     # (-3, 2)    注意：-7 // 3 = -3，-7 % 3 = 2
q, r = divmod(17, 5)   # q = 3, r = 2

为什么值钱：它把 // 和 % 的负数规则捆在一起考 —— Python 的 // 是向下取整（往数轴左边靠），所以负数商往往比"直觉"小 1， 余数则始终与除数同号（除数为正时余数非负）。本站 T6 只讲了 // 与 %，没讲 divmod。

A5 · ASCII 与 Unicode：字符背后都是数字 AIE Week3

概念要点
ASCII美国信息交换标准代码，共 128 个字符；可打印部分是 32–126；只覆盖英文字母、数字和少量符号
Unicode给全世界每个字符一个唯一编号（code point），跨语言跨平台的统一标准；ASCII 是它的子集
常用码点'A'=65，'a'=97，'0'=48；大写整体排在小写前面
Pythonord('A') → 65；chr(65) → 'A'；Python 3 的 str 就是 Unicode 字符串

怎么考：给 ord() / chr() 的结果填空，或问「ASCII 有多少个字符」（128）。

A6 · 字符串字典序比较 AIE Week3

字符串比较是逐字符比码点，第一个不相同的字符直接决定结果；一个是另一个的前缀时，短的更小。

'abc' < 'abcd'   # True   前缀更短 → 更小
'Z'   < 'a'      # True   90 < 97，大写整体排在小写前
'10'  < '9'      # True   先比 '1'(49) 和 '9'(57)，不是按数值比！

丢分点：数字字符串不按数值大小比较。要按数值比必须先 int() 转换。 这条本站 T8 没单列，但它是「字符串 + 比较运算符」混考时的隐形陷阱。

A7 · 浮点精度：0.1 + 0.2 为什么不等于 0.3 AIE Week3

0.1 + 0.2 == 0.3        # False
0.1 + 0.2               # 0.30000000000000004
0.1                     # 存进去其实是
                        # 0.1000000000000000055511151231257827...
  • 分母不是 2 的幂的有理数（如 0.1 = 1/10）无法被精确表示，只能近似。
  • Python 的 float 是 IEEE-754 双精度 64 位，只能精确存约 15–17 位有效十进制数字。
  • 比较浮点不要写 a == b，要写 abs(a - b) < 1e-9。

A8 · bool() 与 falsy / truthy 清单 AIE Week3

会判为 False 的就这几种，背下来：

None          False
0、0.0、0j    （任何数值类型的零）
""            （空字符串）
[]  {}  set()  range(0)      （空容器）

其余一切都是 True，包括这几个最容易上当的：

bool('0')       # True   非空字符串
bool('False')   # True   同理，非空字符串
bool([0])       # True   列表里有一个元素，不是空列表
bool(-1)        # True   非 0 数字都算 True

怎么考：if x: 到底进不进；或者问「下面哪个是 False」。 本站 T10 讲了 if 结构，但没列这份 falsy 清单。

A9 · 求最小值：不能像求最大值那样初始化 AIE Week3

# 求最大值：初始化成 0 勉强能用（全是正数时）
largest = 0
for n in data:
    if n > largest: largest = n

# 求最小值：初始化成 0 就废了 —— 没有任何数会小于 0
smallest = None                      # 正确写法 ①
for n in data:
    if smallest is None or n < smallest:
        smallest = n

# 或者：拿第一个元素起步，从第二个开始比
smallest = data[0]                   # 正确写法 ②
for n in data[1:]:
    if n < smallest: smallest = n

为什么单列：课件专门拿这一页讲「这段程序有什么问题」—— 把求最大值的模板照抄到求最小值上，是初学者最常见的一个 bug。本站 T18 讲 flag 和 trace，没讲这个。

A10 · lstrip() / rstrip()：只删一端的空白 AIE Week4

s = "  hi  "
s.strip()     # "hi"      两端都删
s.lstrip()    # "hi  "    只删左端（leading）
s.rstrip()    # "  hi"    只删右端（trailing）

"xxxy".strip("x")    # "y"   传参 = 指定要删的字符集合
s.strip()            # 返回新字符串，s 本身没变

记住：这三个都不改原串（字符串不可变），返回的是新字符串。 本站 T8 的必背方法表里有 strip()，但没有 lstrip / rstrip。

A11 · startswith()：判断以什么开头 AIE Week4

line = "From professor.xman@uct.edu Sat Jan  5 09:14:16 2008"
line.startswith("From")     # True

# 对比：find() 返回下标，找不到返回 -1（不是 False，也不是报错）
line.find("@")              # 21
line.find("zzz")            # -1
方法返回值找不到时
startswith(x)True / FalseFalse，不报错
find(x)下标（int）-1，不报错
index(x)下标（int）抛 ValueError

配套习惯：课件强调「用 find 找子串前先 lower()」，这样就不用管大小写。 本站 T8 有 find，但没出现 startswith。
