专题 T1 · 计算机基础概念判断 真题 8 题

专题分析

覆盖原题2021 Q1.1 / Q1.3 / Q1.4 / Q2.1；2022 Q1.1 / Q1.6；2023 Q1.1 / Q1.6
考什么冯·诺依曼结构、CPU 内部分工、高低级语言、编译器 vs 解释器、操作系统定位、变量本质
题型单选 / 多选概念判断，纯靠背，属于必须拿满的送分题
易错「开发效率」与「执行效率」反向；「编译器」与「解释器」混淆；把 OS 当成高级程序

必背结论（背下来就够）

  • 冯·诺依曼结构：运算器、控制器、存储器、输入设备、输出设备五大部分，奠定现代计算机基础；不含 GPU。理论基础由图灵奠基。
  • CPU = CU（控制单元：取指令、发号施令）+ ALU（算术逻辑单元：算数与逻辑）。取指令是 CU 的活，不是 ALU。
  • 现代计算机底层只认二进制（0/1）。
  • 高级语言（Python / C / C++ / Java / C#）：开发效率高、可读性好、不能直接执行，必须翻译；执行效率低于低级语言。
    低级语言（机器语言、汇编语言）：程序员要直接面对内存地址与寄存器，开发效率低，但执行效率高。
  • 编译器：把源码整体翻译成目标代码，本身不执行程序；解释器：边翻译边执行。
  • 操作系统是低级程序，负责管理控制计算机活动；计算机可以没有 OS（如嵌入式裸机）。
  • 变量 = 内存中一块被命名的空间；变量名可用下划线开头、可含数字、区分大小写。
ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • Von Neumann architecture has five parts: arithmetic unit, control unit, memory, input devices and output devices. It laid the foundation for modern computers and contains no GPU. The theoretical foundation was built by Alan Turing.
  • CPU = CU (control unit) + ALU (arithmetic/logic unit). The CU fetches instructions and issues control signals; the ALU only does arithmetic and logic. Fetching instructions is never the ALU's job.
  • Modern computers can only understand binary data (0 and 1) at the low level.
  • High-level languages (Python / C / C++ / Java / C#) give higher development efficiency and readability, but cannot be executed directly — they must be translated, and their execution efficiency is lower than low-level languages.
  • Low-level languages (machine language, assembly language) force the programmer to deal with memory addresses and registers directly: lower development efficiency, higher execution efficiency.
  • A compiler translates source code into object code; it does not itself execute the program. An interpreter translates and executes line by line.
  • The operating system is a low-level program that manages and controls a computer's activities; a computer can work without an OS (e.g. embedded bare-metal devices).
  • A variable is a named space in the memory. Names may start with an underscore, may contain digits, and are case sensitive.

Key terms: Von Neumann architecture · control unit (CU) · arithmetic/logic unit (ALU) · binary · high-level language · low-level language · assembly language · compiler · interpreter · operating system (OS) · memory addressing · variable.

Which of the following is NOT a high-level programming language?

A. C/C++ language　B. Java language　C. Assembly language　D. C# language

以下哪一项不是高级程序设计语言？

A. C/C++ 语言　B. Java 语言　C. 汇编语言　D. C# 语言
Answer & Explanation

专题 T2 · 信息单位换算 真题 3 题

专题分析

覆盖原题2021 Q1.5；2022 Q1.5；2023 Q1.5（连续三年第 5 题，问法几乎一样）
考什么最小信息单位；1 Byte = 8 bit；1024 一档的换算链
易错把 Byte 当最小单位（三年都有人错）；1024 写成 1000；240 的 B/bit 单位写混

必须记牢的换算链

bit（最小单位） → 1 Byte = 8 bit → 1 KB = 1024 B = 210 B → 1 MB = 1024 KB = 220 B → 1 GB = 1024 MB = 230 B → 1 TB = 1024 GB = 240 B = 243 bit

  • 易错 1：bit 才是最小信息单位，不是 Byte（三年考三次）。
  • 易错 2：1 KB = 1024 Bytes，不是 1024 bits。
  • 易错 3：换算用 1024（210），写成 1000 的选项一定是错的。
  • 易错 4：单位要看清 B（Byte）还是 bit，1 B = 8 bit，所以 240 B = 243 bit。
ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • bit is the smallest unit of information — not Byte. This has been tested three years in a row.
  • The conversion chain (always 1024 = 210, never 1000):
    bit → 1 Byte = 8 bit → 1 KB = 1024 B = 210 B → 1 MB = 220 B → 1 GB = 230 B → 1 TB = 240 B = 243 bit
  • Trap 1: the smallest unit is the bit, not the Byte.
  • Trap 2: 1 KB = 1024 Bytes, not 1024 bits.
  • Trap 3: any option written with 1000 is wrong — conversions use 1024.

三句口诀

  1. 二进制 ↔ 十六进制：4 位换 1 位。1010=A、1011=B、1100=C、1101=D、1110=E、1111=F。

  2. 二进制 ↔ 八进制：3 位换 1 位。例：011 010 . 011 → 32.3
  3. 转十进制：整数按权展开相加；小数从左往右乘 1/2、1/4、1/8…
    例：11010110.001 = 128+64+16+4+2 + 1/8 = 214.125

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • Binary ↔ hexadecimal: 4 bits ↔ 1 hex digit. 1010=A, 1011=B, 1100=C, 1101=D, 1110=E, 1111=F. Example: AB.D → A=1010, B=1011, .D=1101 → 10101011.1101
  • Binary ↔ octal: 3 bits ↔ 1 octal digit. Example: 011 010 . 011 → 32.3

  • Decimal fraction → another base: multiply the fraction by the target base and take the integer part (repeat until 0).
    0.375 × 16 = 6.0 → take 6 → hexadecimal .6; 0.375 = 0.25 + 0.125 → binary .011.
  • This is exactly where 29.375 = 1D.6 = 11101.011 = 35.3 in 2023 Q1.3 comes from.

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • Only these need to be memorised — let s = "hello world".
  • len(s) → 11. It is a built-in function, not a method: s.length() does not exist.
  • s.split() splits on whitespace → ['hello','world']; s.split('l') → ['he','','o wor','d'] (consecutive separators produce empty strings).
  • s.find('o') returns the index of the first occurrence → 4; returns -1 if not found. s.count('l') → 3.
  • s.upper() / s.lower() → 'HELLO WORLD' / all lower case. s.strip() removes leading and trailing whitespace only (never inside).
  • s.replace('l','L') returns a new string — the original string is unchanged (strings are immutable).
  • Indexing s[3] → 'l', s[-1] → 'd' (negative index counts from the right).
  • Slicing includes the start index but excludes the end index: s[0:5], s[2:], s[:5]; omitting an index means "go to that end".
  • s[::-1] reverses the string (step −1). "umbrella"[2:-1] = "brell" — from index 2 up to before the last character.
  • Methods that do NOT exist on strings: reverse() (use s[::-1]), remove(), length(), append().

Key terms: string method · immutable · index (from 0) · negative index · slice · step · split / separator · strip · find / count / replace · reverse.

别名陷阱（最容易丢分）

a = [1,2,3]
b = a          # b 不是副本，是「同一个列表」的第二个名字
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也被改了

c = a[:]       # 切片才是复制（浅拷贝）
c.append(5)
print(a)       # 仍是 [1, 2, 3, 4]

l1 = l2 = []   # 最阴的写法：两个名字指向同一个空列表

另外两个必记现象：① 遍历列表时往同一个列表 append → 列表不断变长、循环永不结束（2021 Q1.10、Q2.7、2022 Q2.4A）；② 函数里改可变参数（list/dict）会影响外面的对象，改不可变参数（int/str/tuple）不会（见 T11）。

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • str — immutable: s[0]='A' is illegal; concatenation and slicing always produce a new string.
  • tuple — immutable: t[0]=1 ✗, t.append() ✗; but t + (4,) builds a new tuple and t += (4,) rebinds the name.
  • list — mutable: l[0]=1 ✓, and append / extend / sort / remove all work in place.
  • dict — mutable: d[key]=value ✓ (keys must be of an immutable type).
  • Aliasing trap (the easiest place to lose marks):
    b = a does not copy the list — b is simply a second name for the same object, so b.append(4) also changes a.
    c = a[:] is the copy (shallow copy).
    l1 = l2 = [] — two names pointing at the same empty list.
  • Two more phenomena: ① appending to the same list you are iterating over makes it grow forever → the loop never ends; ② modifying a mutable argument inside a function affects the outer object, an immutable one does not.

死循环的三种经典写法

  1. while True: 里没有 break，或 break 永远不成立。
  2. 循环变量不收敛：n -= n-1 使 n 恒为 1。

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • range(5) → 0,1,2,3,4 (5 is excluded); range(1,5) → 1,2,3,4; range(2,10,3) → 2,5,8 (step 3, upper bound still excluded); range(-1,-10,-1) → −1 … −9, 9 numbers.
  • break leaves the whole loop immediately; continue skips the rest of the current pass and starts the next one.
  • for … else: the else block runs only when the loop ended normally (was not stopped by break).
  • Three classic infinite loops: ① while True: with no break, or a break that can never become true; ② the loop variable never converges — n -= n-1 keeps n equal to 1; ③ appending to the list you are iterating over.
  • Double loop counting: the total number of iterations is multiplied, not added (10 × 9, not 10 + 9).

Key terms: loop / iterate · iteration · for loop · while loop · indefinite loop · step · upper bound excluded · break · continue · else clause of a loop · infinite loop · nested loop.

  1. 函数内可以「读」全局变量；但一旦在函数内对某个名字赋值，它在这一整个函数里就被当作局部变量（除非声明 global / nonlocal）。

    x = 1

    print(x)   # 因为下面有 x = 5，Python 认为 x 是本函数的局部变量，此处还没赋值
    x = 5

ENEnglish Key Points · 本专题知识点的英文版（英文考试直接背这个）
  • A function can read a global variable. But as soon as you assign to that name anywhere inside the function, Python treats it as a local variable throughout the whole function (unless you declare global / nonlocal).

    x = 1 → def f(): print(x) … x = 5 — because the assignment below makes x local, and it has not been assigned yet when print runs.
  • Add global x to modify the global one; use nonlocal inside a nested function to modify the enclosing function's local variable.
  • Scope is one-directional: the inner function can read the outer one's variables, but the outer code can never see the inner function's local variables.
